# Tech Context

## Technologies Used
- TypeScript for type-safe development
- React 18 for UI components
- Vite for build and development
- Tailwind CSS for styling
- ShadcnUI for base components
- Lucide React for icons
- Custom game engine implementation

## Development Setup
- Source code in src/ directory
- Clean architecture folder structure:
  - application/: Game engine and managers
  - domain/: Core game logic and types
  - infrastructure/: Services and utilities
  - presentation/: React components
  - components/: UI components
  - components/ui/: ShadcnUI components
  - hooks/: Custom React hooks

## Technical Constraints
- Browser environment (no Node.js specific features)
- React component design patterns
- Tailwind utility classes only
- TypeScript strict mode enabled
- Error handling requirements
- Game state persistence needs
- Maximum 20 hours per day for study activities
- Minimum 1 hour sleep requirement

## UI Components Created
- GameInterface: Main container
- ResourceDisplay: Resource tracking
- EventDisplay: Event interaction
- TimeAllocation: Schedule management
- StressEnergyDisplay: Status display
- NewsGossip: Information feed
- ErrorDialog: Error handling
