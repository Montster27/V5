# System Patterns

## Architecture
- Clean/Hexagonal Architecture
- Domain-Driven Design principles
- Event-driven communication between components

## Layer Structure
1. Domain Layer: Core business logic and types
2. Application Layer: Orchestration and use cases
3. Infrastructure Layer: Technical implementations
4. Presentation Layer: UI components and state management

## Key Patterns
- Event Bus for decoupled communication
- Repository pattern for persistence
- Service pattern for domain logic
- Command pattern for game actions
